# LifeFlow Presentation Guide

Use this order for a clear presentation:

1. Show the Home page and explain the project purpose.
2. Open About and explain the technology stack.
3. Open Donor Register and submit a donor.
4. Login as admin.
5. Show dashboard numbers, blood inventory, alerts, and request queue.
6. Add or edit donor records.
7. Add blood stock.
8. Create a blood request.
9. Issue blood from the transfer page.
10. Show the reports table and explain that transfers are recorded automatically.
