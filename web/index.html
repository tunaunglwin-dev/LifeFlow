About LifeFlow

A simple system for student blood bank projects

LifeFlow shows the full project flow without making the interface confusing. The dashboard is the main workspace, and every feature connects back to donor care, stock control, and transfer records.

Purpose

Help small teams manage blood donation data with simple forms, clear tables, and fast navigation.

Technology

The backend uses C# ASP.NET Core. The frontend uses Vue.js. PostgreSQL stores production data.

Deployment

The API is ready for Render, and the static Vue frontend is ready for Vercel.
